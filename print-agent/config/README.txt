As origens extras do UltraPDV online entram em origins.json.

O arquivo versionado pode permanecer com lista vazia: produção já inclui
https://ultrapdv.app e https://www.ultrapdv.app no código do Conector.

localhost:3000 e 127.0.0.1:3000 sempre são aceitos para desenvolvimento.

Não use Access-Control-Allow-Origin: *. Não coloque domínio de exemplo
no JSON.
