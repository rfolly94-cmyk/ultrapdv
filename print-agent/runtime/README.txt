Coloque aqui o runtime privado do Node (64-bit Windows), extraído do zip oficial:

  print-agent\runtime\node.exe
  print-agent\runtime\LICENSE

Obtenha o zip win-x64 em:
https://nodejs.org/dist/

Exemplo:
  https://nodejs.org/dist/v22.18.0/node-v22.18.0-win-x64.zip

Copie somente node.exe e LICENSE. Não adicione o Node ao PATH.

O instalador distribui este runtime só dentro de:
  C:\Program Files\UltraPDV Connector\runtime\
